## 2026-10-03：立项（用户："先做前两个吧，然后新建俩文件夹，模板都用ICML的模板"）
- **来源**：用户要求参考 Xiaoyu Yang 的思路（选新技术 → 定义一种 concept drift → 建模解决），结合 Zhilin Zhao 的理论，并与 `pdfs/refs/conceptDfift/` 两篇竞品（Drift-Resilient TabPFN, NeurIPS 2024；Lourenço et al., KDD 2026）区分。本项目是当时给出的 Idea 1。
- **问题**：TFM 靠上下文适应数据流。把上下文到新窗口的漂移按 $P(x)P(y|x)$ 分成三类：良性（只有 $P(x)$ 变，virtual drift）、有害（$P(y|x)$ 变，real drift）、新类（sudden drift）。核心问题：没有新窗口标签时，如何判断漂移类型并采取相应行动（保留上下文 / 刷新上下文 / 拒绝）。
- **理论来源**：I-Div（NeurIPS 2024，密度比 r 与似然比 v，估计误差界）为主；DRL（TMLR 2023）用于新类；WNB（MLJ 2024）用于由泛化界推权重。concept drift 定义引 Lu et al. TKDE 2019（不直接引 Xiaoyu 的定义）；"良性/有害漂移解耦"的立意在相关工作中引 Xiaoyu 2505.13081。
- **与已有工作的区别**：AgDR、GOR 是静态的样本级 OOD 检测，并假设已知类的 $P(y|x)$ 不变；本项目的核心是窗口级的 real drift。新类只是其中一种类型，检测可复用 SCDR（作为本组已有工作匿名引用）。
- **已知难点**：只有 $P(y|x)$ 变化、$P(x)$ 不变的漂移，没有标签时无法识别。草稿采用带延迟标签的 prequential 设定，并留了 TODO：检查 I-Div 的似然比在额外假设（如 label shift）下能否给出无标签代理量。
- **已建**：`overleaf/icml/`（ICML 模板，沿用 icml2026.sty，`math.tex`、`refs.bib`）；骨架 `main.tex` 共 3 页，编译通过。所有观察和结果均为计划，无任何实验数字。`code/`、`data/` 为空。
- **下一步**：确定合成流生成器（SEA、Agrawal、hyperplane、RBF；可控漂移类型和幅度）与真实流（Electricity、NOAA、CoverType、PokerHand、Posture）；先跑 Observation 1、2。

## 2026-10-03 约 23:59：Observation 1、2（dev 种子 0–4；`code/obs.py` → `results/obs_dev.csv`）
- **设置**：TabPFN v2（4 个 estimator），上下文 1000 行，漂移后窗口 1000 行。
  - 良性漂移：标签函数不变，P(x) 在支撑集内按 exp(β·u·x) 重要性重采样。
  - 有害漂移：P(x) 不变，标签函数改变（超平面旋转 θ；SEA 阈值移动 Δ）。
  - 新类：Gaussian blobs，上下文只有 4 类，窗口里混入第 5 类，占比 10/20/40%。
  - 比较两种上下文：沿用漂移前的 stale 上下文，或换成同样大小、来自漂移后分布的 fresh 上下文。另记录置信度（max prob）和 P(x) 偏移（TFM 域分类器的 AUROC）。
- **Observation 1（成立）**：漂移类型决定 TFM 是否失效，与 P(x) 偏移的大小无关。
  - 良性漂移：偏移 AUROC 从 0.50 升到 0.93（hyperplane）/0.96（SEA），stale 与 fresh 的准确率差为 0.000–0.001。
  - 有害漂移：准确率差约等于新旧标签不一致率。hyperplane 旋转 90° 时 stale 0.494、fresh 0.981（不一致率 0.508）；SEA Δ=4 时差 0.357（不一致率 0.361）。偏移 AUROC 始终约 0.50。
  - 新类：准确率损失等于新类占比（0.10/0.20/0.40 → 差 0.099/0.197/0.397）。
- **Observation 2（需改写）**：原计划写的是"良性漂移下置信度下降"，**不成立**：支撑集内的良性漂移下置信度不变（0.976–0.980）。实际发现更强：**有害漂移下置信度完全不变**，hyperplane 旋转 90°、准确率 0.494 时置信度仍为 0.977（"自信地错"）。新类行的置信度为 0.84–0.86，已知类行为 0.99，有信号但较弱。
- **推论（对论文最关键）**：只看 P(x) 的无监督漂移检测器，在良性漂移上会强烈报警（偏移 AUROC 0.93，零损失），在有害漂移上完全沉默（AUROC 0.50）；置信度同样看不见有害漂移。因此有害漂移只能靠（延迟的）标签发现，而无标签信号应当用于识别良性漂移和新类，即"不该刷新上下文"和"该拒绝"。这与正文 Remark（可识别性）一致。
- **局限 / 下一步**：良性漂移目前只测了支撑集内的倾斜；还要测超出支撑集的平移（外推），预期良性只在支撑集内成立。论文中 Observation 2 的表述要按以上结果改写。

## 2026-10-04 约 00:00：Observation 1b，超出支撑集的良性漂移（dev 种子 0–4；`code/obs_out.py` → `results/obs_out_dev.csv`）
- **设置**：sine2d，x ~ U([a,a+4]×[−1,1])，y = 1[x₂ < sin(3x₁)]（周期边界，同 Sine 生成器）。上下文 a=0；漂移后窗口用同一标签函数，把 x₁ 的范围平移 s∈{0,1,2,4,8}（s≥4 时与上下文的支撑集不相交）。
- **结果**（stale / fresh / 置信度 / 偏移 AUROC / 到上下文的平均最近邻距离）：
  - s=0：0.988 / 0.984 / 0.986 / 0.51 / 0.05
  - s=1：0.842 / 0.991 / 0.933 / 0.72 / 0.17
  - s=2：0.798 / 0.989 / 0.846 / 0.87 / 0.55
  - s=4：0.576 / 0.990 / 0.681 / 1.00 / 2.05
  - s=8：0.524 / 0.990 / 0.661 / 1.00 / 6.03
- **结论**：良性（virtual）漂移只有在**支撑集内**才是良性的。超出支撑集的平移（这里称"覆盖漂移"）和 real drift 一样有害（s=8 时差 0.466），但它**不需要标签就能检测**：置信度降到 0.66，最近邻距离变大。对比支撑集内的倾斜：置信度不变，偏移 AUROC 可达 0.93，准确率零损失。
- **由此修正的 taxonomy（写进论文定义）**：
  | 类型 | 对 TFM 是否有害 | 能否无标签检测 | 应对 |
  |---|---|---|---|
  | 支撑集内的良性漂移（密度比有界） | 否 | P(x) 检测器会报警，但属于误报 | 保留上下文 |
  | 覆盖漂移（新区域不在上下文支撑集内） | 是 | 能（距离、置信度） | 把新区域加入上下文 |
  | real drift（P(y\|x) 变化） | 是 | 不能（置信度不变，P(x) 不变） | 等延迟标签到了再换上下文 |
  | 新类 | 是 | 部分能（置信度 0.85 对 0.99） | 拒绝该行 |
- **下一步**：在 hyperplane 和 SEA 上补测支撑集内倾斜时的最近邻距离，确认距离能区分倾斜和平移；论文第 2 节的定义按上表改写（virtual drift 拆成 covered 和 uncovered，后者对应 I-Div 中密度比无界的情形）。

## 2026-10-04 约 00:03：无标签的覆盖统计量（dev；`code/coverage_check.py` → `results/coverage_dev.csv`）
- **统计量**：窗口行到上下文的平均最近邻距离，除以上下文内部的留一最近邻距离（=1 表示窗口和上下文自身一样被覆盖）。

## 2026-10-04 00:15：数据流基准与冒烟测试（`code/stream_bench.py`、`code/stream_eval.py`；只有 dev 种子 0，非结论）
- **基准**：两个族。sine2d：周期边界，新类是 sine 区域上方的一条带（在原支撑集之外）。lin：K 个线性类，argmax Wx，新类由新激活一个类向量产生（在原支撑集之内）。每 3000 行发生一次事件（tilt / translate / real / novel，两轮随机顺序，状态逐段累积），批量 B=100，标签延迟一批，上下文 M=1000。策略：fifo、ltm（KDD 26，短期比例 0.75）、ddm（Gama 2004 规则触发重置）、pxreset（kNN 两样本分类器 AUROC>0.75 时重置，属于无监督 P(x) 检测器）、triage v0。
- **冒烟结果**：
  - 整体准确率：lin 上 fifo 0.951、ltm 0.950、ddm 0.970、pxreset 0.949、triage v0 0.966；sine2d 上依次为 0.973、0.974、0.980、0.972、0.976。
  - real drift 后 10 批的准确率：lin 上 fifo 0.694、ddm 0.906、triage 0.865；sine2d 上 fifo 0.822、ddm 0.943、triage 0.865。
  - pxreset 只在 tilt 和 translate 上重置（lin 和 sine2d 各 4 次），real drift 时 0 次，与 Observation 2 的推论一致：P(x) 检测器误报良性漂移、漏掉 real drift。
- **重要发现**：对 in-context 学习器来说，**重置上下文的代价很小**，TFM 靠一两百行就能重新学会当前概念，所以 DDM 这样"有错就重置"的简单策略已经很强，关键在于 real drift 的检测速度。这与 trained model 不同：后者重置意味着要重新训练。
- **triage v0 的两个设计缺陷**：
  1. 对比用的"近期上下文"取的是第 t−3、t−2 批，漂移刚发生时它仍是漂移前的数据，检测滞后约 3 批。
  2. 新类行的标签到达后会让当前上下文的损失变大，被误判成 real drift 并触发重置（lin 上 1 次）。重置后上下文变小，置信度变得嘈杂，新类检测 AUROC 从 fifo 的 0.873 降到 0.628（ddm 也降到 0.601）。
- **v1 修改（只在 dev 上）**：real drift 检验改为在最新标签批内做 2-fold 交叉拟合，与当前上下文对同一批行的预测比较；只用当前上下文中已有类别的行（按定义，real drift 只针对已知类）；新类行不触发重置。
- **更正**：本日志 10-04 前几条的标题时间原先是估计值，已按结果文件的修改时间改正（obs_dev.csv、obs_out_dev.csv、coverage_dev.csv、stream_smoke/）。以后的时间一律以 `date` 为准。
