# 学术写作原则(The Press-Release Principle，v2)

## 一句话原则

论文是一场学术发布会，不是项目总结、实验日志或自我审查报告。
你的任务不是平均呈现这项工作的所有方面，而是识别其中最值得发表的价值，
并围绕这一价值建立最完整、最有说服力的叙事。

**总约束：改的是叙事，不是证据。** 凡是"删、换、不提"的操作，只对与核心主张无关的内容做。
与核心主张相关的不利结果，用收窄主张来处理，并保留一句如实的说明。

## 一、叙事规则

1. **只围绕优势组织论文。** 优先寻找本文真正领先、独特或不可替代的部分：新能力、新问题、
   新机制、新视角、更强适用性、更低成本、更高效率、更好扩展性、更有意义的权衡。
   没有形成优势的内容，不进入主线（可以进附录）。
2. **不写成工作汇报。** 不按"我们先做了什么、后来尝试了什么、哪些失败了"的过程展开。
   只保留最终成立的逻辑：问题为什么重要 → 现有方法为什么不够 → 本文提供了什么新解法 →
   证据如何支持。
3. **不占优的维度，不作为主张，但结果照报。** 某指标不占优势，就不要把叙事建立在该指标上，
   也不要就它提出主张。任务定义、评价指标、比较口径和测试集在看到结果之前定下，之后不换；
   能调整的是主张的范围：明确本文在什么条件下领先，把主张收窄到这个条件。
4. **优势必须被明确说出来。** 不要期待审稿人自己从表格中发现贡献。主动解释：
   本文在哪个条件下表现最好、为什么这种优势会出现、解决了什么实际问题、为什么值得关注。
5. **控制比较范围。** 不追求"所有数据集、所有指标全面领先"。只提出证据能牢固支撑的主张。
   说服力来自主张与证据高度一致，而不是比较项目数量最多。
6. **允许彻底重构故事。** 现有结果无法支撑原始叙事时，不要围绕原叙事防守。重新定义问题、
   重排贡献、重做标题摘要引言和实验结构。故事服务于最强证据，而非忠于最初设想。
   重构的是问题的提法、贡献的排序和主张的范围；主结果仍是事先定好的那组指标和测试集上的结果。

## 二、语言规则(防自我削弱)

- 禁用自我削弱式表达:"遗憾的是""仅""仍明显落后""效果有限""存在严重不足"。
- **如实陈述，不渲染。** 不占优的结果用中性的事实句写出数字和条件（"在 X 上与 Y 持平""在 X 上低 0.3 点"），
  不加评价性的形容词，也不回避。按顺序判断:
  ①该结果是否关系到核心主张——关系到就必须报告;
  ②能否收缩主张，使它不再依赖这个结果;
  ③是否体现某种权衡——只有在有证据支持时才这样解释（例如代价、延迟、适用条件的实测数字）;
  ④与核心主张无关的，可以移到附录或删去。
- 某项结果不构成优势时,不必提炼成结论,更不应帮读者把局部现象上升为对整体方法的否定。

## 三、实验规则

实验不是结果仓库，而是论证工具。每个实验必须承担明确职责之一：

- 证明核心方法有效;
- 证明优势来自关键机制;
- 证明方法在目标场景中具有价值;
- 排除最可能的替代解释。

不承担上述职责的实验：
- 与核心主张无关的，删除或移到附录;
- 与核心主张相关但结果不利的，保留（正文或附录），并用一句话如实说明;
- 不为了得到想要的结果而重新设计已经跑过的 test；新设计的实验在新数据上做，并说明它是事后加的。

## 四、结构规则

**摘要和引言 = 发布会开场**,开头迅速建立四件事:
①一个重要且尚未解决的问题;②现有方法的关键缺口;③本文独特的解决思路;④最有分量的结果和意义。
不从实现细节、研究过程或大量背景知识开始,不在贡献尚未建立时提前讨论不足。

**结论只强化记忆点**:本文解决了什么、提出了什么、证明了什么、为什么重要。
不在最后一段突然加入新的自我否定或扩大局限性。

**局限写在专门的一段里**（ICML、NeurIPS 等的 checklist 要求）：简短、具体、限定范围，
说清楚主张在什么条件下成立；不分散在全文各处，不写成自我否定。

## 五、默认决策规则(遇到不理想材料时,按优先级处理)

1. 删除与核心主张无关的内容;
2. 缩小主张,避免无意义的正面对比;
3. 有证据时，将结果解释为目标差异或合理权衡;
4. 重组实验,使优势成为视觉和叙事中心;
5. 重新定义论文故事（问题的提法与主张的范围）;
6. 凡是影响核心结论的结果，必须说明——用一句中性的事实句，放在它该出现的位置。

## 六、交稿前自查

**不给审稿人递刀子：**
- 这句话是否无意中扩大了本文需要承担的责任?
- 是否提出了一个本来没人要求回答的问题?
- 是否把局部现象描述成了普遍缺陷?
- 是否使用了比证据更宽泛的负面判断?
- 有没有按"我们做了什么过程"在展开?
- 有没有把不领先的指标设成了主战场?
- 摘要前五句里,问题和贡献都出来了吗?
- 结论里有没有突然的自我否定?

**不给审稿人留把柄：**
- 有没有略去与核心主张相关的不利结果?
- 指标、比较口径或测试集有没有在看到结果之后改过?
- 每一个主张是否都有对应的表格或图，且范围不超过证据?
- "权衡"的说法有没有实测数字支持?
- 局限段有没有，是否具体?

不主动制造审稿问题,不主动扩大攻击面,不主动替反方完成论证；也不留下审稿人一查就能发现的缺口。

## 最终目标

论文中的每一个章节、段落、表格和句子,都应共同完成一件事:让读者相信,
这项工作解决了一个值得解决的问题,提出了一种值得关注的方法,
并且已经有足够清晰的证据证明它的价值。
找到真正成立的优势,围绕它组织全部材料,并把这个优势讲到足够清楚。
