## 2026-10-06 02:04：立项方向（用户："这样难道不是很好吗，已经有问题了，但是研究的不深度，我们做 yangxiaoyu 定义的流"）；Gray Learning 原文要点；修复机制的探查（运行前写定）

- **读了 Gray Learning（Zhao、Cao、Wang，TNNLS 2023）的引言、第 III 节和定理 1、2**：
  - 设定：训练数据 P_M = (1−α)P_I + αP_O，其中 OOD 样本不属于任何已知类，却被标成了已知类；测试只有 ID。
  - 观察：不管样本是 ID 还是 OOD，它的**补标签**（"不属于哪些类"）总是可靠的：ID 样本不属于给定标签以外的类，OOD 样本不属于任何类。
  - 方法：每个样本同时算给定标签的损失 L_G 和补标签的损失 L_C，按预测置信度 C(x,y)=Q_θ(y|x) 自适应加权——置信度高的靠给定标签，低的靠补标签。
  - 理论：定理 1 给出在混合数据上训练的假设相对 ID 最优假设的超额风险界，首项是 2α·d_H(P_I,P_O)（污染比例乘以两个分布的差异）；定理 2 把 GL 的目标写成带约束的交叉熵。
- **搬到 in-context 流上的初步设想（Claude 的设想，尚无证据）**：
  - 自定义的流问题："灰流"——到达的带标签的行来自 P_{M,t}=(1−α_t)P_{I,t}+α_t P_{O,t}，标签的可靠度 α_t 本身随时间变（成批的错标、系统性的错标、新类被标成旧类）。它和概念漂移在标签上看起来一样：都是"新到的行与上下文矛盾"。
  - 对 TFM，"学习"就是把行放进上下文，没有损失权重可调；GL 的"按置信度在给定标签与补标签之间加权"要变成对上下文的改写。置信度可以用 context swap（留出自身所在折的预测）得到，上一条已测到它识别错标行的 AUROC 为 0.91。
  - 噪声与漂移的区分：与旧行矛盾但与最近的行一致的是漂移，应当保留；与新旧邻居都矛盾的是噪声。
- **本次探查要回答的问题**：有没有一种只靠标签改写（不训练）的机制，能把 20% 污染造成的损失拿回一半以上？上一条里"删掉最可疑的 20%"只挽回 22%。
- **变体**（都只对 TabPFN 的上下文做，9 个数据源 × 5 个种子，对称 20% 与非对称 20% 两种污染；置信度一律来自 5 折留出预测）：
  - noisy（不处理）、clean（上界）、oracle_drop（删掉真正被改的行，检测完美时"删除"的上界）、oracle_fix（把被改的行改回去，等于 clean，用来核对）；
  - drop_dis：留出预测的类别与给定标签不同且给定标签的概率 < 0.2 的行删掉（不需要知道污染比例）；
  - relabel：同样的行不删，改成留出预测的类别；
  - relabel2：在 relabel 之后的标签上再做一轮留出预测与改标；
  - soft4：每行复制 4 份，标签按 q = c·(给定标签) + (1−c)·(留出预测在其余类上的分布) 分配，c 为给定标签的留出概率——这是 GL"置信度高靠给定标签、低靠补标签"在上下文里的直接对应；
  - rep4：每行原样复制 4 份（对照，检验复制本身是否改变预测）。
- **判定（运行前写定）**：若某个非 oracle 的变体在对称 20% 下平均挽回 ≥ 50% 的损失，且在 9 个数据源中至少 7 个上不变差，同时在非对称 20% 下平均挽回 ≥ 30%，就认为"修复机制存在"，下一步在流上做 Observation；否则修复仍是开放问题（这本身也可以是论文的切口，但方法要另想）。

## 2026-10-06 02:22：重读 Zhilin 的三篇 TPAMI 与 AIJ（用户："重读 zhilin paper，主要是 3 篇 TPAMI 和 AIJ，看看能不能结合 xiaoyuyang 思路做流"）
- **读的范围**：四篇都读了摘要、引言里的方法概述、方法一节的开头和定理陈述（文本抽取后阅读）；证明和实验细节没有读。
- **SA（Supervision Adaptation，TPAMI 2023，45(12)）**：设定是混合分布 P(x)=(1−ε)P_I(x)+εP_O(x)，OOD 样本**没有标签**；目标是在 ID 泛化与 OOD 检测之间取得平衡；用"混合空间互信息"把 OOD 样本的监督信息写成对所有类的负概率，再用一组二元回归去估计它。
- **CA（Distilling the Unknown to Unveil Certainty，TPAMI 2025，47(10)）**：用一条参数化的马尔可夫链把 OOD 样本（噪声）逐步变成 ID 样本，沿途用权重函数 α(t)=(t/T)^a 把网络的预测分布与均匀分布混合（"置信度修正"），用这些带修正置信度的样本蒸馏出一个 ID/OOD 二分类器；定理 1 的泛化界通过 φ(a)=(a+1)(2a+1)/a² 依赖权重函数的指数 a。
- **FIG（TPAMI 2023）**：由判别器输出的负熵定义一个隐式的能量生成器，用 Langevin 采样得到"高置信度的 OOD 样本"，再用压平其类别概率的正则项微调判别器；没有形式化的定理（文本里搜不到 Theorem）。
- **TC（Regaining Lost Clues，AIJ 2025）**：信息瓶颈使分类网络只用与标签强相关的特征、丢掉弱相关的线索，于是在表格数据上对 OOD 过度自信；用一串 transformer 逐级把弱特征再分解成强、弱两组来找回线索；定理 1 给出集成假设的泛化界，随链长参数 q 变化。
- **与 Yang 的"自定义流"结合的可能（Claude 的设想，都没有证据）**：
  1. **SA + GL → "混合流"**（即本项目）：两篇的设定是同一个混合分布，只是 OOD 样本一个被错标、一个没有标签。流的版本是 P_{M,t}=(1−ε_t)P_{I,t}+ε_t P_{O,t}，ε_t 随时间变；SA 提供"ID 泛化与 OOD 检测的平衡"这条评价轴和"未标注行的自适应监督"。流里最近的行本来就没有标签（标签延迟），所以 SA 的无标签一侧是天然存在的。
  2. **CA → "涌现"：一个类在上下文里从 OOD 变成 ID**。CA 的马尔可夫链是"OOD 逐步变成 ID"，在流里这是真实发生的过程：新类刚出现时应当拒识，随着它的带标签的行进入上下文，逐渐变成应当分类的已知类。α(t) 对应"随上下文里该类行数增长的置信度修正日程"，CA 的界对应日程指数的选择。TFM 特有的问题是：某个类在上下文里只有几行时，它的置信度怎么修正。
  3. **TC → "相关性漂移"**：哪些特征与标签强相关随时间改变（特征漂移是流学习里已有的题目）；旧上下文让 TFM 继续依赖原来的强特征，丢掉已经变成唯一线索的弱特征。方法上对应"特征子集上的一串 in-context 专家"。它与 AgDR 的 Defect B 是同一个现象在时间上的版本。
  4. **FIG**：与流的结合最弱（需要微调判别器，而 TFM 是冻结的），不建议。
