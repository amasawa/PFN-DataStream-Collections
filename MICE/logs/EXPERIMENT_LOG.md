# MICE 实验日志

本文件只记录 MICE（Mixture of In-Context Experts）的工作；AgDR、GOR、DriftTriage 各有自己的日志。

## 2026-10-03：立项（用户："先做前两个吧，然后新建俩文件夹，模板都用ICML的模板"）
- **来源**：同 DriftTriage（Xiaoyu 思路 + Zhilin 理论 + 区别于两篇竞品）。本项目是当时给出的 Idea 2。
- **问题**：数据流中反复出现的概念（recurring drift）。对 TFM 来说，每个历史区间的上下文都是一个零训练成本的"离线专家"。核心问题：在当前窗口标签到达之前，如何召回匹配的历史概念，并识别从未出现过的新概念。
- **理论来源**：MOOE（AAAI 2025）为主，包括离线/在线专家、元专家，Thm 2 的 regret 界和 Thm 3 的泛化界；in-context 专家无需训练，可去掉 Thm 1 的参数收敛项。I-Div（NeurIPS 2024）用于无标签时给专家加先验权重；R-divergence（NeurIPS 2023）用于合并相似的专家。
- **与竞品的区别**：KDD 2026 那篇用 FIFO 短期和长期记忆，不建模概念复现；Drift-Resilient TabPFN 需要重训先验，外推的是趋势。MICE 免训练，可在标签到达前召回历史概念，检测新概念，并有 regret 保证。与 AgDR、GOR 基本不重叠（问题、数据、主理论都不同）。
- **已建**：`overleaf/icml/`（ICML 模板，沿用 icml2026.sty，`math.tex`、`refs.bib`）；骨架 `main.tex` 共 3 页，编译通过。所有观察和结果均为计划，无任何实验数字。`code/`、`data/` 为空。
- **下一步**：查 recurring-concept 方向的基线（如 RCD、集成池类方法）；准备含已知复现的合成流（SEA、Agrawal、STAGGER、周期切换的 RBF）与真实流（Electricity、NOAA）；先跑 Observation 1（FIFO 遗忘复现概念）。

## 2026-10-04 00:24：两个更强的基线，以及对 MICE 不利的发现（冒烟，stagger_s0）
- **新基线（`run.py`）**：
  - ddm1000：上下文取上次 DDM 检测（Gama 2004）之后的标签行，超过 M 行时按 FIFO；
  - winens1000：100、300、1000 行三个 FIFO 窗口作专家，用与 mice1000 相同的 hedge 规则（η=2，γ=0.5）加权。它只能快速适应，没有历史记忆。
- **结果（stagger_s0）**：fifo 0.852、ltm 0.853、mice 0.930、**ddm 0.972、winens 0.972**、oracle 0.994。
- **结论（需在全部 dev 流上确认）**：至少在 STAGGER 这种简单概念上，MICE 相对 FIFO 的提升主要来自更快的适应，而不是对历史概念的记忆；in-context 学习器靠约 100 行就能重新学会当前概念，所以"快速重学"已经很强。DriftTriage 的冒烟测试也得出了同样的结论（重置上下文代价很小）。
- **影响**：MICE 必须胜过 ddm 和 winens 才有论文结论。真正要回答的问题变成："什么时候记住历史概念比在上下文里快速重学更好？"预期取决于重学一个概念需要多少行（概念复杂度）。sea、stagger 很少的行就够；agrawal、sine、rbf 可能需要更多。
- **MICE v1 计划（dev）**：专家池之外，在线专家改为 100、300、M 三个窗口（把快速适应也纳入），再用缓存离线调权重规则（`reweight.py`）。所有 dev 流都补跑 ddm1000、winens1000、micecache1000。

## 2026-10-04 00:29：MICE v1 与离线加权分析（冒烟，stagger_s0）
- **MICE v1**（`run.py` 中的 micev）：在线专家改为 100、300、1000 行三个 FIFO 窗口，加上历史专家池；每个专家每一批的预测都缓存到 `.pkl`。`reweight.py` 可以离线比较加权规则（hedge η∈{1,2,5,10,20}、γ∈{0,0.5,0.8}，以及 leader）和专家子集（全部 / 只用窗口 / 只用专家池加 M 窗口）。
- **结果**：stagger_s0 上 micev1000 为 0.9723，与 winens、ddm 相同。所有规则和子集都是 0.9723，复现后前 5 批都是 0.873。
- **解释**：0.873 正是"标签延迟一批"下的上限，即（切换后第一批的准确率 0.38 + 4）/ 5 ≈ 0.876。STAGGER 的概念用 100 行就能在一批内重新学会，任何快速方法都已触顶，记忆不可能再有贡献；P(x) 又不变，无标签的召回也无从谈起。
- **对 MICE 研究问题的修正**：记忆只在"重学一个概念需要的行数"相对"概念持续的时间"较大时才有价值，这正是 MOOE 理论里离线专家占优的条件（当前区间的标签样本有限）。论文的核心问题改为"召回 vs 重学"的权衡：
  - 理论：召回的额外损失约为识别所需的批数，重学的额外损失约为重学的样本代价，两者比较；
  - 实验：可控地改变概念复杂度（RBF 质心数）和块长，验证记忆的收益随"重学代价 / 块长"增大而增大；再看真实流（INSECTS reoccurring、Elec2）落在哪个区间。
- **下一步**：mice-dev 跑完后，在全部 dev 流上补跑 ddm1000、winens1000、micev1000，并新建一个可控的复杂度和块长网格（只在 dev 种子上）。

## 2026-10-04 01:30：网格的两个种子完成；学习曲线可以定量预测记忆的收益（dev；`code/predict_gain.py`）
- **网格全部完成**（GRID_DONE 01:29:55）。micev（η=10、γ=0）相对 ddm 的提升，两个种子的均值：c5 +0.2/+0.2；c30 +1.7（b500）/+0.6（b2000）；c100 +8.7/+3.0。12 个流中 10 个为正，两个 c5 的流为 −0.07 和 −0.16 点。两个种子的方向和量级一致。

  - Spearman 1.0，Pearson 0.999。c100_b500 预测偏高（0.117 对 0.087），原因是模型假设召回从第二批起就选中正确专家，实际识别还需要时间。
- **意义**：这是 MICE 论文的核心理论检验："召回 vs 重学"的权衡可以由 TFM 的学习曲线面积事先预测，不只是方向，量级也吻合。论文的命题应写成：召回的收益等于学习曲线在重现区间上的面积减去识别代价，再用这张预测与实测对照表验证。

## 2026-10-04 07:27：以 R-divergence（NeurIPS 2023）为核心是否可行——原始定义在对称冲突下失效，超额风险形式可行（dev 种子 0；`code/check_rdiv.py` → `results_grid_dev/rdiv_check.csv`）
- **动机**：用户要求 Zhilin 的文章优先仿照 TPAMI、NeurIPS 的。MICE 的主理论目前来自 MOOE（AAAI），所以检验能否把核心换成 R-divergence：把冻结的 TFM 当作"模型"，用它判断新段与已存专家是否同一概念。

  - rdiv：R-divergence 原始定义，|risk_p(h_u) − risk_q(h_u)|，h_u 是以两段混合数据为上下文的 TFM（交叉拟合）；
  - transfer：risk_q(h_p) − risk_q(h_q)，即 MICE 现在用的合并准则；
  - excess：两段各自的 risk(h_u) − risk(h_own) 取较大者，即混合给每一段带来的超额风险。

- **结论**：可以把 R-divergence 作为核心，但要用超额风险形式（混合后的风险与各自风险之差）。论文的链条可以是：R-divergence 的模型导向观点 → 它在对称冲突下的失效（Observation，可证明）→ 超额风险形式的定义 → 该量同概念时等于学习曲线增量 → "召回 vs 重学"的面积公式。MOOE 的元专家只负责加权。
- **限制**：只有 dev 种子 0，每条流 12 对；excess 需要额外的 TFM 调用；transfer（现方法）已经同样有效，所以这一步改进的是理论的出处和严密性，不是准确率。尚未改动冻结的方法。

- **读了 R-divergence 原文第 3、4 节**：定义 D_R(p‖q)=|ε_p(h*_u)−ε_q(h*_u)|；Thm 4.1 是估计量的收敛界（2·L-divergence + 两个 Rademacher 复杂度 + 12c√(ln(8/δ)/N)），Cor 4.5 给出 N→∞ 时估计量 ≤ 2D_L + D_R。原文没有讨论"两个分布互相矛盾但混合假设在两边风险相同"的情形。
- **新结论（总体层面，已证明，见草稿）**：把 TFM 理想化为"上下文来自混合 U 时输出 U(y|x)"（PFN 的后验预测解释），log-loss 下
  1. 超额风险形式 D_E = ½[ε_P(h_U)−ε_P(h_P)] + ½[ε_Q(h_U)−ε_Q(h_Q)] = JS(P,Q) − JS(P_X,Q_X) ≥ 0，即联合分布的 JS 散度里协变量偏移解释不了的那部分；P_X=Q_X 时等于条件 JS 散度，当且仅当条件分布几乎处处相同时为 0。
  2. 盲点：P_X=Q_X 且两个概念都是确定性标注时，无论分歧质量 ρ 多大都有 D_R=0，而 D_E=ρ·ln2；0-1 损失下 ε_P(h_U)=ε_Q(h_U)=ρ/2，转移形式 D_T(Q|P)=ε_Q(h_P)−ε_Q(h_Q)=ρ=2D_E。
  3. 有限上下文：同概念时超额风险 = R(2n)−R(n) ≤ 0（学习曲线增量的相反数），所以"超额 ≤ δ 就合并"等价于"合并的收益大于概念间的干扰"；MICE 实际用的合并统计量是 D_T 的估计，也就是"召回这个专家在该段上的遗憾"。

## 2026-10-04 20:59：小间隔情形的界成立但没有信息量；真实流上的提升来自混合的多样性项（缓存重放，不调用 TFM；`code/check_persist.py`）
- **检验的界**：权重取自上一批损失（η=10）时，由 Jensen 不等式 ll_mix(j) ≤ min_k ℓ_k(j) + Σ_k w_k Δ_k + δ_j，Δ_k 是上一批上与最优专家的损失差，δ_j 是相对损失在相邻两批之间的最大变化。
- **结果（逐批平均，nat）**：
  - held-out 真实流：实际遗憾（混合减每批最优专家）0.005–0.056；Σw·Δ 为 0.030–0.035；δ 为 0.19–1.42；界为 0.22–1.46。界在 100% 的批次上成立，但比实际遗憾大 10–40 倍，δ 由权重几乎为 0 的差专家决定。
  - dev 网格：实际遗憾 0.15–1.54（主要来自每个块的第一批），界 0.62–4.24，同样宽松。
- **多样性项**：专家损失的加权平均减最优专家为 0.045–0.150，而混合的实际遗憾只有 0.005–0.056，即混合比"按权重随机选一个专家"好 0.04–0.09 nat。这一差值正是 log-loss 下的多样性项 Σ_k w_k E[ln(p_mix(y)/p_k(y))] ≥ 0（恒等式）。
- **结论**：(a) "持续性"这条修补路线得不到有内容的保证，不写进理论。(b) 真实流上 MICE 相对单个专家和窗口集成的提升，可以用恒等式 ll_mix = Σw·ℓ_k − 多样性项 如实描述：存储的专家给混合增加了彼此不同的成员。这是描述，不是预测，和网格上的"召回 vs 重学"是两种机制。
- **对论文叙述的影响**：应当分开写——合成网格（概念难、间隔大）验证召回机制与面积公式；真实流上的提升幅度小（0.2–0.9 点），机制是混合的多样性，不能说成"认出了复现的概念"。
