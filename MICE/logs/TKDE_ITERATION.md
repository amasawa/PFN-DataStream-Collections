## 第 1 轮（2026-10-09T00:54+11:00）

**1. Codex 指出的问题**（gpt-6-astra high）。P1：核心定理"recall versus relearn"的等式在给定条件下不成立，对它的数值验证也没有按定理计算。
- 证明里假设"两个学习器第一批都会丢分"，但标签晚到一批，并不能推出两者第一批的准确率相等；等式因此漏了一项 $(A^{mix}_1-A^{rel}_1)/J$。
- 预测脚本对每次复现都用 $M=1000$ 行的存储上下文，而定理规定第 $c$ 次访问时 $n_c=\min(M,(c-1)L)$，$L=500$ 时第二次访问只有 500 行。按定理重算，100 中心这一格是 9.21，论文报的是 10.44。

**2. Claude Code 的判断与解决方式：接受。** 我独立核实，两点都成立。
- 第一批：两个学习器在第一批都还没拿到这一块的标签，但混合器用的是旧概念的专家，relearn 的上下文刚被清空，两者准确率可以不同，所以等式确实漏了这一项。
- 预测：`predict_gain.py`、`check_grid_test.py`、`make_paper_tables.py` 用的都是 `acc(M)`；预注册的 PRED 值也是这样算出来的。
- 我按定理重算，写成 `MICE/code/predict_gain_visit.py`，输出 `results_grid_test/predicted_visit.csv`：只有 L=500 的两格有变化（100 中心 10.44→9.21，30 中心 1.91→1.71），两组 Spearman 仍是 0.943 / 0.829，数值和观测值更接近（9.2 对 8.6）。

修改（`MICE/overleaf/tkde/main.tex`，方法不变）：
- 定理显式加入第一批项 $\varepsilon_{k,c}$，并证明 $|\varepsilon_{k,c}|\le 1/J$；求和部分命名为"面积项"。
- 推论改为"面积项为零"，上界加上 $1/J$；附录证明相应改写。
- RQ1 新增一段：说明预注册值用了简化假设（每次复现都存满 $M$ 行），给出按定理重算的值和相关系数；表和图仍报预注册值，因为它们是运行前固定的；说明定理假设在块边界精确重置，而实际比较对象是 DDM，检测延迟和慢层都不在定理范围内，所以数值吻合只是近似，第一批项也没有被预测。
- 表注和图注改为"预注册值，见 RQ1"。

**3. 结论：** 理论陈述已改到严格成立，预注册的结论（排序相关）不受影响，数值吻合程度略有改善。ICML 版没有改。

**4. MiMo 验证结果（v2.6 Pro high；只读副本，只读附件）：**
- 第 (2) 部分没有问题。RQ1 新段落里的每个数字都与 `predicted_visit.csv` 一致；MiMo 独立重算 100 中心、L=500 这一格，得到 9.2135。
- 第 (1) 部分：$\varepsilon_{k,c}$ 及其界、推论的上界都正确。另有两个 P2，我核实后已修复：

## 第 2 轮（2026-10-09T01:04+11:00）

**1. Codex 指出的问题**（gpt-6-astra high）。P1，评估缺口：实验没有把 MICE "按概念组织的回忆"和"保存更多历史 + 调用更多专家"这两种收益分开。MICE 最多保留 12 个 1000 行的上下文、评估最多 15 个专家；去掉记忆池的消融会同时去掉历史数据和专家调用。也没有一个同等资源、使用同样两层聚合、但不做基于差异的合并的历史上下文集成作为对照。

**2. Claude Code 的判断与解决方式：接受。**
- 我的判断：在网格流上，12 个 500 行快照能覆盖最近 6000 行，正好是 K=3 的一到两个完整周期，所以一个不做合并的档案库也可能取回同一概念。没有这个对照，"按概念合并有价值"这一主张确实没有被检验。这是需要补的实验，方法本身不改。
- 实现：`MICE/code/run.py` 新增 `PoolControl`，它就是 MiceV1 去掉概念组织那一步，窗口、池大小（12）、两层聚合和所有常数都不变：

  - `snap1000_500`：每关闭一段就保存最近 1000 行的快照，存储量与 MICE 相同。
- 冒烟测试：`arch` 正常运行（8 个池专家，每批最多 11 个专家，两层聚合可以离线重放）；`snap` 在测试时遇到一次间歇性 CUDA 失败，当时和 held-out 共享 GPU，之后会单独重跑。
